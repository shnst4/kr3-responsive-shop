Converse Shop — контрольная работа №3
Тема
Адаптивная вёрстка и доступность многостраничного HTML/CSS-сайта.
Основа проекта
КР №3 создана на основе моего проекта КР №1. Bootstrap не используется.
Страницы
`index.html` — главная страница, преимущества и популярные модели.
`catalog.html` — каталог с демонстрационной формой фильтров.
`product.html` — информация о товаре и таблица характеристик.
`order.html` — форма заявки.
`contacts.html` — контакты магазина.
Файлы
`css/index.css`, `css/catalog.css`, `css/product.css`, `css/order.css`, `css/contacts.css` — стили из КР №1.
`css/responsive.css` — новые адаптивные стили и оформление фокуса.
`js/main.js` — существующий JavaScript главной страницы.
`img/` — изображения товаров.
`lighthouse/` — отчёт о проверке доступности (после выполнения проверки).
Изменения для КР №3
Добавлена ссылка «Перейти к содержимому» в начале каждой страницы.
Основному блоку `<main>` добавлены `id="main-content"` и `tabindex="-1"`.
Дополнена доступность навигации, изображений и таблицы.
Добавлены стили Mobile First для навигации, карточек, каталога, формы и таблицы.
Добавлены заметный фокус клавиатуры и поддержка `prefers-reduced-motion`.
Что проверить перед сдачей
Проверить все страницы на ширинах 320, 375, 768, 1024 и 1440 пикселей.
Убедиться, что нет горизонтальной прокрутки страницы.
Проверить клавишей Tab ссылку для пропуска навигации, меню, кнопки и форму.
Проверить модальное окно главной страницы, если используется `js/main.js` из КР №1.
Запустить Lighthouse → Accessibility на основных страницах, исправить найденные замечания.
Сохранить свой реальный отчёт или скриншот в `lighthouse/` и описать результат ниже.
При необходимости дополнить проект изображениями с разными размерами для `srcset` и `sizes`, а также вариантом `<picture>`.

Запуск
Открыть `index.html` в браузере или через Live Server в VS Code.
